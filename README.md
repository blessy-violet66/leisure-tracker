# Leisure Tracker - Chatbot

## About the Project
Leisure Tracker is a simple chatbot that helps users find activities to do during their free time. It suggests different activities based on the user's interests, mood, and available time. The main idea behind this project is to help people discover new hobbies and make their leisure time more enjoyable.

## Features
- Suggests activities based on user messages.
- Recommends indoor and outdoor activities.
- Provides ideas for relaxation, entertainment, and learning new hobbies.
- Suggests activities based on available time.
- Includes quick prompts for easy interaction.
- Simple and responsive user interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## How It Works
The chatbot uses JavaScript to check keywords in the user's message and provide suitable activity suggestions from a predefined list. For example, users can ask for indoor activities, hobbies, or things to do when they are bored.

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start chatting with the Leisure Tracker chatbot.

## Project Structure
- `index.html` – Contains the chatbot interface.
- `style.css` – Contains the design and styling.
- `script.js` – Contains the chatbot logic and activity suggestions.
